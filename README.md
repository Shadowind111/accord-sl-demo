# ACCORD-SL research demo (retired)

This repository previously hosted a T1 20-item demonstration. The final ACCORD-SL release uses the **T1 Blood3** contract (age + basophil percentage + ALT + albumin), with threshold 0.134, and T2 11-marker scoring with threshold 0.237.

The final code, model card, and release assets are maintained at:

- https://github.com/Shadowind111/accord-sl
- https://github.com/Shadowind111/accord-sl/releases/tag/v11.0.0

No old 20-item T1 model or old threshold is part of the final release. This repository is retained only as a public landing page.
